# 꼬마 스파이 크리스마스 대작전

## 오프닝

**등장인물** : 스파이더, 포라미, 박사님(영상)

**동선** : 무대 오른쪽 등장 → 가운데 → 무대 오른쪽 퇴장

※ 오른쪽과 왼쪽은 모두 관객이 보는 방향 기준입니다. (무대 위 아이들 기준으로는 반대)

---

(무대가 어둡다. 스파이 음악이 작게 흐른다.)

**스파이더(하임)** : (손전등을 켜고, 무대 오른쪽에서 몸을 낮춰 살금살금 걸어 나온다.)

**스파이더(하임)** : (두리번거리며 손전등으로 무대 여기저기를 비춘다.)

**포라미(서하)** : (스파이더 뒤에 바짝 붙어 살금살금 따라 나온다. 뒤를 두리번거리며 살핀다.)

**둘다** : (한 걸음씩 멈춰 두리번거리며 무대 가운데까지 걸어간다.)

**둘다** : (가운데에 도착해 등을 맞대고 선다.)

[조명]

**스파이더(하임)** : (한 발 앞으로 나와 포즈) 나는 스파이더!

**포라미(서하)** : (한 발 앞으로 나와 포즈) 나는 포라미!

**둘다** : (같이 포즈) 우리는! 꼬마 스파이!

(삐삐삐 무전 소리와 함께 스크린에 박사님이 나타난다.)

**둘다** : (깜짝 놀라 귀에 손을 댄다.)

**박사님** : 스파이들, 응답하라. 여기는 박사.

**둘다** : (경례) 네! 박사님!

**박사님** : 이번 크리스마스, 교회에 도움이 필요한 사람들이 있다. 몰래 도와주고 와라.

**스파이더(하임)** : (고개를 갸웃) 몰래요?

**박사님** : 그렇다. 절대! 들키면 안 된다.

**둘다** : (서로 마주 보고, 입에 손가락을 댄다) 쉿! 비밀 작전!

**둘다** : (비밀 신호 동작을 한다.)

**포라미(서하)** : (몸을 낮추고, 두리번거리며 무대 오른쪽으로 살금살금 걸어간다.)

**스파이더(하임)** : (포라미 뒤를 따라 살금살금 걸어가며, 뒤를 한 번 더 두리번 살핀다.)

**둘다** : (무대 오른쪽으로 퇴장한다.)

(영상이 시작된다.)

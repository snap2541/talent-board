# 엔딩. 마지막 무전

**등장인물** : 스파이더, 포라미, 본부(목소리)

**동선** : 무대 오른쪽 끝에서 멈춤 → 가운데로 돌아옴 → 인사 → 무대 왼쪽 퇴장

※ 오른쪽과 왼쪽은 모두 관객이 보는 방향 기준입니다.

---

**둘다** : (무대 오른쪽 끝에서 멈춘다. 깜짝 놀라 귀에 손을 댄다.)

**둘다** : (서로 보고, 두리번거리며 무대 가운데로 살금살금 돌아온다.)

**본부** : 스파이들, 응답하라.

**둘다** : (경례) 네! 본부!

**본부** : 모든 작전 완료. 아무도 너희를 못 봤다.

**스파이더(하임)** : (어깨를 축 늘어뜨리며) 근데 본부... 아무도 모르면 좀 섭섭해요.

**본부** : 괜찮다. 다 보고 계신 분이 있으니까.

**포라미(서하)** : (고개를 갸웃) 누구요?

**본부** : 우리 대장님이시지.

**둘다** : (서로 마주 보고 크게 끄덕인다) 아~!

**스파이더(하임)** : (관객을 보며) 성경에 이렇게 나와요!

**둘다** : 오른손이 하는 것을 왼손이 모르게 하라! (마태복음 6장 3절)

**포라미(서하)** : 여러분도 몰래 도와주는 스파이가 되어 주세요!

**둘다** : (비밀 신호 포즈) 메리 크리스마스!

**둘다** : (꾸벅 인사한다.)

**둘다** : (입에 손가락을 대고 쉿!)

**스파이더(하임)** : (자세를 낮추고, 두리번거리며 무대 왼쪽으로 살금살금 걸어간다.)

**포라미(서하)** : (스파이더 뒤를 따라 살금살금 걸어간다. 관객을 돌아보며 손을 흔든다.)

**둘다** : (무대 왼쪽으로 퇴장한다.)

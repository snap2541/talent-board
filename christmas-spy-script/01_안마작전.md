# #1

**등장인물** : 스파이더, 포라미, 어른

**동선** : 무대 오른쪽 등장 → 가운데(의자) → 무대 왼쪽 퇴장

※ 오른쪽, 왼쪽은 관객 기준입니다.

## [무대]

[조명]

(무대 가운데 의자에 어른이 앉아 졸고 있다.)

(스파이 음악)

**스파이더(하임)** : (무대 오른쪽에서 자세를 낮추고 살금살금 걸어 나온다.)

**스파이더(하임)** : (멈춰서 두리번두리번 주변을 살핀 뒤, 뒤를 보고 따라오라고 손짓한다.)

**포라미(서하)** : (자세를 낮추고 살금살금 따라 나온다. 두리번거리며 뒤를 살핀다.)

**둘다** : (한 걸음씩 살금살금, 두리번거리며 의자 쪽으로 다가간다.)

**둘다** : (의자 뒤로 가서 쪼그려 앉는다.)

**스파이더(하임)** : (의자 옆으로 고개만 빼꼼 내밀어 어른을 살핀다.)

**포라미(서하)** : (어른의 어깨를 손가락으로 콕 찔러 보고, 깜짝 놀라 손을 턴다.)

**둘다** : (서로 마주 보고 고개를 끄덕인 뒤, 비밀 신호를 한다.)

(안마 음악 시작)

**둘다** : (일어나서 어른 뒤에 한 명씩 선다. 스파이더는 오른쪽, 포라미는 왼쪽.)

**스파이더(하임)** : (음악에 맞춰 어른의 오른쪽 어깨를 주먹으로 콩콩콩 두드린다.)

**포라미(서하)** : (음악에 맞춰 어른의 왼쪽 어깨를 주먹으로 콩콩콩 두드린다.)

**스파이더(하임)** : (손날로 어른의 오른쪽 어깨를 다다다 빠르게 두드린다.)

**포라미(서하)** : (손날로 어른의 왼쪽 어깨를 다다다 빠르게 두드린다.)

**스파이더(하임)** : (엄지로 어른의 오른쪽 어깨를 꾹꾹 누른다.)

**포라미(서하)** : (엄지로 어른의 왼쪽 어깨를 꾹꾹 누른다.)

**스파이더(하임)** : (주먹을 높이 들었다가 어른의 오른쪽 어깨를 뿅뿅 두드린다.)

**포라미(서하)** : (주먹을 높이 들었다가 어른의 왼쪽 어깨를 뿅뿅 두드린다.)

**어른** : (몸을 뒤척이며) 음...?

(음악이 뚝 멈춘다.)

**둘다** : (그 자세 그대로 얼음!)

**둘다** : (재빨리 의자 뒤로 숨는다.)

**어른** : (다시 고개를 떨구고 쿨쿨 잔다.)

**둘다** : (고개를 빼꼼 내밀어 서로 보고, 휴~ 이마를 닦는다.)

(음악 다시 시작)

**스파이더(하임)** : (양손으로 어른의 등을 데굴데굴 문지른다.)

**포라미(서하)** : (어른의 어깨에 무언가를 살짝 덮어 준다.)

**둘다** : (서로 보고 엄지척, 입에 손가락을 댄다.)

**포라미(서하)** : (자세를 낮추고, 두리번거리며 무대 왼쪽으로 살금살금 걸어간다.)

**스파이더(하임)** : (어른을 한 번 돌아보고, 포라미 뒤를 따라 살금살금 걸어간다. 두리번거리며 뒤를 살핀다.)

**둘다** : (무대 왼쪽으로 퇴장한다.)

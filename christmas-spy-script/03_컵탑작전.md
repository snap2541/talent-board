## [무대]

[조명]

(무대 가운데에 높은 선반이 있다.)

(스파이 음악)

**스파이더(하임)** : (무대 오른쪽에서 자세를 낮추고 살금살금 나온다.)

**포라미(서하)** : (스파이더 뒤에 붙어 어깨에 두 손을 얹는다. 기차처럼 살금살금 따라 나온다.)

**둘다** : (몇 걸음 가다가 멈춘다. 둘이 동시에 왼쪽, 오른쪽 두리번두리번.)

**둘다** : (다시 살금살금 걷다가 멈춰서 두리번두리번. 한 번 더 반복한다.)

**둘다** : (선반 앞에 도착한다. 기차를 풀고 나란히 선다. 스파이더는 오른쪽, 포라미는 왼쪽.)

**스파이더(하임)** : (위를 가리키며 까치발을 든다. 손이 안 닿는다.)

**포라미(서하)** : (폴짝 뛰어 본다. 역시 안 닿는다.)

**둘다** : (서로 보며 고민하는 표정, 턱을 만진다.)

**포라미(서하)** : (번뜩! 손뼉을 짝 친다.)

**둘다** : (비밀 신호를 한다.)

(음악이 점점 빨라진다.)

**포라미(서하)** : (선반 뒤로 돌아가 몸을 숨긴다. 관객에게는 가림막에 가려 보이지 않는다.)

**스파이더(하임)** : (선반 앞에 서서 두 손을 내밀고 위를 올려다본다.)

**포라미(서하)** : (선반 뒤에서 컵을 하나 휙 던진다.)

**스파이더(하임)** : (컵을 받고 깜짝 놀란 표정. 몸을 숙여 가림막 뒤에서 뭔가 하는 척한다.)

**포라미(서하)** : (또 하나 휙 던진다.)

**스파이더(하임)** : (또 받는다. 놀란 표정으로 관객을 보고, 다시 몸을 숙여 가림막 뒤에서 뭔가 하는 척한다.)

**포라미(서하)** : (컵을 점점 빠르게 던진다.)

**스파이더(하임)** : (허둥지둥 받으며 점점 더 바쁘게 움직인다. 숙였다 일어나기를 반복한다.)

(음악이 뚝 멈춘다.)

**스파이더(하임)** : (몸을 깊이 숙였다가, 미리 만들어 둔 컵 탑을 두 손으로 들고 천천히 일어선다. 방금 쌓은 것처럼 놀란 표정으로 관객을 본다.)

**포라미(서하)** : (선반 뒤에서 나와 탑을 올려다보며 놀란 표정을 짓는다.)

**둘다** : (탑이 흔들린다! 둘이 양손으로 탑을 받친다.)

**둘다** : (조심조심 손을 뗀다. 탑이 서 있다.)

**둘다** : (휴~ 이마를 닦는다.)

(음악 다시 시작)

**포라미(서하)** : (선반 위의 컵을 집어 높이 든다.)

**둘다** : (같이 컵을 들고 만세!)

**둘다** : (무대 앞쪽으로 나와 컵을 바닥에 살짝 놓는다.)

**둘다** : (입에 손가락을 댄다.)

**포라미(서하)** : (왼쪽을 보고 자세를 낮춘다. 기차 맨 앞이 된다.)

**스파이더(하임)** : (포라미 뒤에 붙어 어깨에 두 손을 얹는다.)

**둘다** : (기차처럼 무대 왼쪽으로 살금살금 걸어간다. 멈출 때마다 둘이 동시에 두리번두리번.)

**둘다** : (무대 왼쪽으로 퇴장한다.)
